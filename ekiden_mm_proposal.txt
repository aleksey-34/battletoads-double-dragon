ПРЕДЛОЖЕНИЕ ПО СОТРУДНИЧЕСТВУ - Market Making Bot для Ekiden
Алексей, май 2026


ЗАДАЧА
Создать собственного маркет-мейкера для Ekiden - наполнение стаканов, снижение зависимости от внешних MM-провайдеров.


ЧТО БУДЕТ ПОСТРОЕНО

Коннектор:
- Авторизация Ed25519 (JWT + API-key)
- REST: выставление, изменение, отмена ордеров (одиночные и batch до 20 шт.)
- WebSocket: стакан в реальном времени, поток исполнений
- Обработка rate limits, автопереподключение

Grid Filler:
- Лимитные ордера в заданном диапазоне с заданным шагом
- post_only = true (maker fee 0% на Ekiden)
- При исполнении - немедленный переставление на том же уровне через batch API
- SMP - бот не торгует сам с собой

Управление позицией:
- При смещении позиции - автосдвиг котировок для балансировки
- Лимиты по экспозиции через конфиг

Адаптивный спред:
- Расширяется при высокой волатильности
- Пауза при аномальных движениях

Надежность:
- При потере соединения - отмена всех ордеров, safe mode до восстановления
- JSON логи: ордера, fills, позиция, PnL
- CLI: запуск / пауза / стоп / статус

Архитектура под расширение:
- Signal/alpha layer - подготовлен, активируется на этапе 3
- Легко добавить: Telegram, новые пары, Docker

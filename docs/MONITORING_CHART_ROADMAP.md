# Monitoring chart — roadmap

## Сейчас (Jul 2026)

- График мониторинга: **только линии метрик** (Equity по умолчанию, абсолютная шкала).
- Маркеры сделок IN/OUT на графике **отключены** — засоряли чарт и ломали читаемость.
- Счётчик «Сделок за 24ч» и список сделок в Positions остаются как есть.

## Позже

1. **Список сделок по ключу** — отдельная панель/таб под графиком, данные из БД по запросу.
2. **Восстановление истории** — `GET /api/monitoring/:key/trades?from=&to=` (или reuse `/api/trades/:key`).
3. **Опционально на графике** — чекбокс «Показать сделки», sparse markers без текстовых лейблов или tooltip по клику.
4. **Шкалы** — при нескольких метриках: либо dual-axis (USD + %), либо нормализация с явной подписью оси.

Файлы: `MonitoringChartPanel.tsx`, `Positions.tsx`, backend monitoring snapshot + trades API.

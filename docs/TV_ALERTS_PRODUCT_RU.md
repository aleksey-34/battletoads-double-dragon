# BattleToads TV Alerts — продукт для покупателя

## Что это

**TV Alerts** — отдельный режим платформы BattleToads без витрин и готовых стратегий. Вы торгуете **только по своим сигналам** из TradingView: алерт срабатывает → webhook приходит на наш сервер → позиция открывается на вашей бирже с заданным риском, выставляются TP/SL (в том числе лесенкой), трейлинг отслеживается до закрытия. Следующий сигнал обрабатывается по вашим правилам (ждать закрытия или заменить позицию).

Подходит трейдерам и авторам Pine-стратегий, которые уже получают edge на TradingView и хотят **исполнение на бирже**, а не копирование чужих «карточек» из каталога.

## Ключевые возможности

| Блок | Описание |
|------|----------|
| **Регистрация** | При создании аккаунта выбираете режим «TradingView Alerts» — отдельный личный кабинет `/cabinet/tv-alerts`. |
| **Биржи** | Bybit, Bitget, BingX, Binance, MEXC, WEEX — подключение API-ключей клиентом (non-custodial: ключи на вашей бирже). |
| **Алерты** | Несколько независимых алертов: символ, биржа, ключ, лот в **USDT** или **% от депозита**, плечо. |
| **Webhook** | Уникальный URL на каждый алерт; в TradingView — Essential и выше (webhook). |
| **TP / SL** | Несколько ног: фиксированный % от цены входа, сетка (offset %), частичное закрытие (% позиции на ногу). |
| **Трейлинг** | Программный трейлинг-стоп с настраиваемой дистанцией % (мониторинг каждые ~15 с на runtime). |
| **Конфликт сигналов** | Если позиция уже открыта: ждать закрытия / принять новый / закрыть и открыть новую. |
| **Ручной терминал** | Long/Short, закрыть % или всё, отменить биржевые ордера. |
| **Журнал** | Лог всех webhook и ручных действий с ошибками биржи. |

## Как подключить TradingView

1. В ЛК создайте алерт, скопируйте **Webhook URL**.
2. В TradingView: Alert → Notifications → Webhook URL.
3. В сообщении алерта (рекомендуется JSON):

```json
{
  "action": "{{strategy.order.action}}",
  "symbol": "{{ticker}}",
  "price": {{close}}
}
```

Поддерживаются также текстовые команды: `buy BTCUSDT`, `short ETHUSDT`, `close`.

**Важно:** для webhook нужен платный план TradingView (от ~$13–15/мес Essential, 20 активных алертов). Это оплата TradingView, не нашей платформы.

## Безопасность

- API-ключи только с правами торговли, **без вывода**.
- Webhook защищён секретом в URL; при утечке — «Regenerate secret» в ЛК.
- Исполнение на сервере с фиксированным egress IP (whitelist на WEEX и др.).

## Техническая архитектура (кратко)

```
TradingView Alert → POST /api/webhooks/tradingview/:tenant/:alert/:secret
                 → tvAlerts/engine (parse, sizing, placeOrder)
                 → exchange connectors (Bybit, CCXT…)
                 → trigger TP/SL on exchange + trailing monitor (runtime 15s)
```

Отдельный `product_mode = tv_alerts_client`, таблицы `tv_alerts`, `tv_alert_positions`, `tv_alert_events`.

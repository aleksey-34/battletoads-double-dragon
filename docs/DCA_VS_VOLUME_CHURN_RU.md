# Classic DCA vs volume-churn (hamster / Саша)

## Два разных продукта

| | **Classic DCA** (наш TS+DCA scan) | **Volume-churn** (скрины HYPE 5m, Саша $10) |
|---|-----------------------------------|---------------------------------------------|
| Цель | Добор просадки + TP от средней | Объём (rebate), много round-trip |
| Направление | Long-only сетка | Long ↔ Short по очереди |
| Выход | TP всей сетки (редко) | Таймер ~5 мин или микро-TP |
| Размер | % депозита, сетка step | ~99% депа на сделку |
| Trades в отчёте | **1 trade = 1 закрытая сетка** | **1 trade = каждый open+close** |
| За 2 года 15m | десятки–сотни циклов | **тысячи** (как на графике hamster) |

INSANE DCA (step 0.12%, TP 0.2%, 15m) **не превратится** в hamster: пока сетка открыта, новый цикл не стартует.

## Пример Саши ($10 → $3396 volume за ночь)

- Открыть почти весь деп → закрыть через 5 мин → снова, L/S чередовать.
- Объём = сумма notional всех сделок; PnL может быть около нуля, комиссия съедает.
- «Без плеча» / изолированная маржа — риск не ликвидация, а **комиссия + проскальзывание**.

Бэктест «медленный слив» / «с тейками ровно вниз» — типично для **частых выходов + комиссия**, не для Classic DCA.

## Что у нас в коде

- **Classic DCA**: `strategy_type=dca`, backtest `engine.ts`, live `bot/dca.ts`.
- **Volume-churn**: отдельного режима **нет** (нужен новый тип: timed exit, short, счётчик fills).

## Масштабирование лота DCA

- **% депозита** считается от **deposit equity** (initial + reinvest×PnL), с тем же reinvest, что у TS.
- Вход **ограничен свободной маржой** (чтобы не блокировать trend), но **не** «4% от free margin как база» — это был баг.

## Куда двигаться для «как на скрине, но безопаснее»

1. Отдельная стратегия **Volume churn** (5m, hold N bars, alt L/S, TP > fee, no close in red).
2. Не смешивать с Donchian TS в одном combined wallet без лимита DCA budget (% капитала только на churn).
3. Бэктест: метрики **fills**, **turnover USDT**, **fee drag** — не только «циклы сетки».

Пока для TS-карточки: DCA — **добавка к тренду**, не замена hamster.
